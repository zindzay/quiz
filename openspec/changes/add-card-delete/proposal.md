# Proposal

## Why

Карточки можно только добавлять. Ошибочные, устаревшие или повторяющиеся по смыслу вопросы (в том числе созданные скилами импорта) остаются в базе навсегда, попадают в тесты и на повторение. Убрать их сейчас можно только правкой CSV при остановленном приложении.

## What Changes

- **Удаление на странице «Все карточки»** (`/cards.html`): у каждой карточки кнопка «Удалить».
- **Подтверждение на самой карточке:** после нажатия «Удалить» на месте кнопки появляется «Удалить карточку?» с кнопками «Да» и «Отмена». Системные окна браузера не используются.
- После «Да» карточка удаляется из хранилища и пропадает из списка без перезагрузки. Если карточек не осталось — показывается сообщение о пустом списке со ссылкой на добавление.
- При ошибке сервера карточка остаётся в списке, на ней — сообщение об ошибке.
- **API:** `DELETE /api/cards/{id}` — 204 при удалении, 404 если карточки нет.
- Удалённая карточка больше не попадает в тесты, в том числе если была на повторении.
- Разметка элемента списка меняется: раскрытие ответа и кнопка «Удалить» — отдельные элементы внутри карточки (вложенные кнопки недопустимы). Внешне раскрытие работает как раньше.

Вне рамок этого изменения:
- отмена удаления (корзина, «Вернуть»);
- массовое удаление;
- удаление со страницы теста;
- редактирование карточек.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `cards`: добавляется требование «Удаление карточки» (`DELETE /api/cards/{id}`).
- `cards-web-ui`: добавляются требования «Удаление карточки в списке» и «Ошибка удаления карточки».

## Impact

- `src/main/java/org/valgor/quiz/`:
  - `repository/CardRepository`, `CsvCardRepository` — метод удаления с атомарной перезаписью файла;
  - `service/CardService`, `web/CardController` — `DELETE /api/cards/{id}`;
  - тесты `CsvCardRepositoryTest`, `CardServiceTest`, `CardApiTest`, `RestartPersistenceTest`.
- `src/main/resources/static/`:
  - `cards.html` — шаблон карточки, блок подтверждения;
  - `cards.js`, `styles.css`.
- `ui-tests/`:
  - e2e `cards-list.spec.ts` — сценарии удаления; поиск карточек меняется, потому что в списке появляются кнопки «Удалить»;
  - скриншоты страницы списка — **эталоны меняются**, обновляются после того, как пользователь посмотрит новые скриншоты.
- `README.md`, `CLAUDE.md` — удаление и метод API, правило поиска карточек в e2e.
- Формат CSV и новые зависимости — без изменений.
