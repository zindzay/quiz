# Spec Delta

## ADDED Requirements

### Requirement: Удаление карточки
Система SHALL удалять карточку по запросу `DELETE /api/cards/{id}` и отвечать 204 без тела. Удаление MUST сохраняться в файле данных и переживать перезапуск; удалённая карточка MUST NOT возвращаться ни в списке, ни в случайной выборке, даже если была на повторении. Если карточки с таким `id` нет, система MUST ответить 404 с JSON-полем `error`.

#### Scenario: Карточка удалена
- **WHEN** сохранены карточки A и B, и клиент выполняет `DELETE /api/cards/{id}` для A
- **THEN** система отвечает 204, а `GET /api/cards` возвращает только `[B]`

#### Scenario: Удаление переживает перезапуск
- **WHEN** карточка удалена, а приложение перезапущено с тем же файлом данных
- **THEN** `GET /api/cards` не содержит удалённой карточки

#### Scenario: Удалённая карточка на повторении не попадает в тест
- **WHEN** карточка на повторении удалена, и клиент выполняет `GET /api/cards/random?count=10`
- **THEN** в ответе нет удалённой карточки

#### Scenario: Карточка не найдена
- **WHEN** клиент выполняет `DELETE /api/cards/{id}` для несуществующего `id`
- **THEN** система отвечает 404 и JSON-объектом с полем `error`
