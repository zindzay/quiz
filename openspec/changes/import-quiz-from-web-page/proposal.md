# Proposal

## Why

Чтобы наполнить приложение карточками по какой-то статье или документации, сейчас приходится вручную придумывать вопросы и вводить их по одному через форму. Скил Claude Code может прочитать страницу по ссылке, составить по ней набор карточек «вопрос — ответ» и сразу добавить их в приложение.

## What Changes

- Новый скил Claude Code `quiz-from-web-page` в `.claude/skills/`:
  - на вход — URL страницы и, по желанию, количество карточек;
  - скил загружает страницу, выделяет основной текст и генерирует карточки только по её содержанию;
  - карточки отправляются в запущенное приложение через `POST /api/cards`;
  - вопросы, которые уже есть в приложении, пропускаются;
  - в конце скил показывает итог: сколько карточек добавлено, сколько пропущено и сколько завершилось ошибкой.
- Вспомогательный скрипт для отправки карточек в API. Его переиспользует будущий скил импорта из PDF.

Вне рамок этого изменения:
- страницы, которые требуют авторизации или рендерятся только JavaScript;
- поле «источник» у карточки (это потребовало бы менять формат CSV);
- ручное ревью карточек перед отправкой.

## Capabilities

### New Capabilities

- `quiz-from-web-page`: генерация карточек по содержимому веб-страницы и их добавление в приложение.

### Modified Capabilities

Нет.

## Impact

- `.claude/skills/quiz-from-web-page/SKILL.md`: новый скил.
- `tools/quiz-import/post_cards.py`: скрипт отправки карточек (python3, только стандартная библиотека).
- `CLAUDE.md`: раздел о скилах импорта.
- Зависит от изменения `add-card-view-and-create`: нужны `GET /api/cards` и `POST /api/cards`. Java-код не меняется.
