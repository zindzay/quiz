# Spec Delta

## MODIFIED Requirements

### Requirement: Вызов скила
Скил SHALL принимать обязательный путь к локальному PDF-файлу, необязательный диапазон страниц (`N` или `N-M`) и необязательное количество карточек от 1 до 50. Если количество не указано, скил SHALL работать в автоматическом режиме и сам определять число карточек (см. «Автоматический выбор количества карточек»). Если файла нет, он не PDF, диапазон некорректен или выходит за число страниц, скил MUST сообщить об ошибке до генерации карточек.

#### Scenario: Вызов с путём
- **WHEN** пользователь вызывает скил с путём `docs/lecture.pdf` на 8 страниц без количества
- **THEN** скил работает в автоматическом режиме и сам определяет число карточек по содержанию всего документа

#### Scenario: Вызов с диапазоном и количеством
- **WHEN** пользователь вызывает скил с путём, диапазоном `3-5` и количеством 6
- **THEN** скил генерирует не больше 6 карточек только по страницам 3–5

#### Scenario: Неверные аргументы
- **WHEN** путь указывает на несуществующий файл или на `.txt`, либо диапазон `10-20` при 8 страницах
- **THEN** скил сообщает об ошибке и не отправляет карточки

## ADDED Requirements

### Requirement: Автоматический выбор количества карточек
В автоматическом режиме скил MUST выделить все ключевые положения выбранных страниц документа (определения, факты, числа, причины и следствия, шаги процессов, сравнения) и создать по одной карточке на каждое положение. Число карточек SHALL быть равно числу ключевых положений и MUST NOT ограничиваться 50. Каждая часть документа с осмысленным содержанием MUST дать хотя бы одну карточку.

#### Scenario: Короткий документ
- **WHEN** в двухстраничном PDF без указания количества изложены четыре независимых факта
- **THEN** скил создаёт четыре карточки, по одной на факт

#### Scenario: Лекция с несколькими разделами
- **WHEN** пользователь без указания количества импортирует 40-страничную лекцию с несколькими разделами
- **THEN** скил создаёт карточки по ключевым положениям каждого раздела, и их число определяется содержанием, а не значением по умолчанию

### Requirement: Проверка полноты покрытия
В автоматическом режиме скил MUST перед отправкой сверить список ключевых положений с набором карточек и создать карточки для непокрытых положений. Итоговый отчёт MUST содержать число ключевых положений, число покрытых и разбивку карточек по частям документа (диапазонам страниц).

#### Scenario: Все положения покрыты
- **WHEN** импорт PDF в автоматическом режиме завершён
- **THEN** отчёт содержит строку вида «ключевых положений: 27, покрыто: 27» и число карточек по каждому диапазону страниц

#### Scenario: Непокрытое положение найдено при сверке
- **WHEN** при сверке выясняется, что для одного из ключевых положений нет карточки
- **THEN** скил создаёт для него карточку до отправки, и в отчёте все положения покрыты

### Requirement: Подтверждение большого набора
Если в автоматическом режиме получилось больше 150 карточек, скил MUST до отправки показать пользователю их число и разбивку по частям документа и MUST NOT отправлять карточки без его подтверждения.

#### Scenario: Большой набор
- **WHEN** в автоматическом режиме по 100-страничному документу получилось 170 карточек
- **THEN** скил сообщает число и разбивку, спрашивает подтверждение и ничего не отправляет до ответа
