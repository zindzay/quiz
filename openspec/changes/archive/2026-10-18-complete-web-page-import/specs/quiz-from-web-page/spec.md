# Spec Delta

## ADDED Requirements

### Requirement: Обработка полного текста страницы
Скил MUST строить карточки по всему основному тексту страницы, полученному без пересказа и сокращения, если его объём не превышает 500 000 символов. Если текст длиннее, скил SHALL обработать первые 500 000 символов и MUST указать в отчёте, какая доля текста не обработана.

#### Scenario: Длинная статья обрабатывается целиком
- **WHEN** пользователь импортирует статью с основным текстом около 130 000 символов
- **THEN** скил обрабатывает весь текст, и в наборе есть карточки по разделам из второй половины статьи

#### Scenario: Текст сверх лимита
- **WHEN** основной текст страницы длиннее 500 000 символов
- **THEN** скил обрабатывает первые 500 000 символов и сообщает в отчёте долю необработанного текста

### Requirement: Распределение карточек по разделам
Скил SHALL распределять карточки по всему тексту пропорционально объёму его частей. Если запрошенное количество не меньше числа крупных разделов страницы, каждый крупный раздел с осмысленным содержанием MUST дать хотя бы одну карточку.

#### Scenario: Карточки из каждого раздела
- **WHEN** пользователь запрашивает 10 карточек по статье из 5 крупных разделов
- **THEN** каждый из 5 разделов представлен хотя бы одной карточкой

#### Scenario: Карточек меньше, чем разделов
- **WHEN** пользователь запрашивает 3 карточки по статье из 8 крупных разделов
- **THEN** скил создаёт не больше 3 карточек из разных разделов, а не из первых трёх абзацев

### Requirement: Отчёт о покрытии
Итоговый отчёт скила MUST содержать объём обработанного текста (в символах и в процентах от основного текста страницы) и список разделов, по которым созданы карточки.

#### Scenario: Отчёт после полного импорта
- **WHEN** импорт завершён
- **THEN** отчёт содержит строку вида «обработано 131 200 из 131 200 символов (100 %)» и перечень разделов, давших карточки

### Requirement: Запасной путь для страниц без статического текста
Если из HTML страницы не удалось извлечь основной текст (меньше 500 символов, например страница собирается JavaScript), скил SHALL получить содержимое запасным способом и MUST предупредить в отчёте, что полнота для этой страницы не гарантируется.

#### Scenario: Страница, собранная JavaScript
- **WHEN** HTML страницы содержит только пустой контейнер и скрипты
- **THEN** скил получает текст запасным способом, создаёт карточки, если текст есть, и предупреждает в отчёте, что полнота не гарантируется
