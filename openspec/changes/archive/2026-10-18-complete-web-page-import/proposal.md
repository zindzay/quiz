# Proposal

## Why

При проверке `/quiz-from-web-page` на статье Википедии «HTTP» (около 133 000 символов) WebFetch вернул пересказ на пару экранов, а не текст: его вспомогательная модель сжимает содержимое и читает не больше 100 000 символов за вызов. Карточки получились верными, но по малой части статьи. Целые разделы — заголовки, коды состояния подробно, безопасность — в набор не попали. Для учебных карточек важна полнота: карточки должны строиться по всему тексту страницы и равномерно покрывать её разделы.

## What Changes

- Текст страницы извлекается **без пересказа**. Новый скрипт `tools/quiz-import/fetch_page.py` сам загружает HTML, выделяет основное содержимое (`<main>`/`<article>`, без навигации, скриптов, стилей, меню, футера) и сохраняет полный текст с заголовками разделов.
- Текст делится на **части** по разделам, не больше ~12 000 символов каждая. Скил читает части по очереди и генерирует карточки для каждой с квотой, пропорциональной её объёму, затем объединяет результаты. Так карточки покрывают всю страницу, а не её начало.
- **Отчёт о покрытии**: сколько текста обработано (символы и доля), какие разделы дали карточки.
- **Запасной путь**: если скрипт не нашёл текста (страница рендерится JavaScript), скил использует WebFetch, как сейчас, и предупреждает, что полнота не гарантируется.
- Верхняя граница объёма — 500 000 символов основного текста. Сверх неё скил обрабатывает начало страницы и сообщает, какая доля пропущена.

Вне рамок этого изменения:
- выполнение JavaScript (headless-браузер);
- страницы за авторизацией;
- обход нескольких страниц.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `quiz-from-web-page`: добавляются требования «Обработка полного текста страницы», «Распределение карточек по разделам», «Отчёт о покрытии» и «Запасной путь для страниц без статического текста». Существующие требования не меняются.

## Impact

- `tools/quiz-import/fetch_page.py` и `tools/quiz-import/test_fetch_page.py` — новые файлы (python3, только стандартная библиотека).
- `.claude/skills/quiz-from-web-page/SKILL.md` — шаги загрузки и генерации переписываются, в `allowed-tools` добавляется `Bash(python3 tools/quiz-import/fetch_page.py:*)`.
- `tools/quiz-import/README.md`, `CLAUDE.md` — описание нового скрипта.
- Зависит от `import-quiz-from-web-page`: его нужно заархивировать первым, чтобы основная спецификация `quiz-from-web-page` существовала до архивации этого изменения.
- Импорт длинных страниц станет дольше и дороже по токенам: читается весь текст, а не пересказ. Для статьи на 130 000 символов — примерно 11 частей.
