# Spec Delta

## ADDED Requirements

### Requirement: Одна мысль — одна карточка
Скил импорта MUST создавать по одной карточке на мысль источника: утверждение вместе с его причиной, условием, следствием, противопоставлением или способом применения. Скил MUST NOT делить одну мысль на несколько карточек и MUST NOT склеивать в одну карточку разные мысли, отвечающие на разные вопросы. Вопрос карточки MUST оставаться одним вопросом, а ответ — не длиннее 3 предложений.

#### Scenario: Утверждение и его следствие
- **WHEN** в тексте сказано «`List.of()` создаёт неизменяемый список; чтобы его можно было изменять, нужно преобразовать его в `ArrayList`»
- **THEN** скил создаёт по этой мысли одну карточку, ответ которой содержит и неизменяемость, и преобразование в `ArrayList`, а не две карточки

#### Scenario: Утверждение и противопоставление
- **WHEN** в тексте сказано «обход циклом `for` полезен, когда нужен доступ к соседним элементам; в остальных случаях проще `for-each`»
- **THEN** скил создаёт одну карточку о выборе между `for` и `for-each`

#### Scenario: Разные мысли не склеиваются
- **WHEN** в тексте описаны метод `set()`, заменяющий элемент по индексу, и метод `remove()`, удаляющий элемент по индексу
- **THEN** скил создаёт две карточки, по одной на метод

#### Scenario: Без составных вопросов
- **WHEN** скил объединяет утверждение и его следствие в одну карточку
- **THEN** вопрос карточки — один вопрос, например «Как работать со списком из `List.of()`, если его нужно изменять?», а не «Какой список создаёт `List.of()` и как сделать его изменяемым?»

#### Scenario: Слияние при проверке набора
- **WHEN** при проверке набора две карточки оказываются двумя сторонами одной мысли
- **THEN** скил заменяет их одной карточкой, все положения этой мысли ссылаются на неё, а отчёт сообщает о слиянии
