# Proposal

## Why

Веб-интерфейс (`cards-web-ui`) сейчас проверяется только вручную: автотест подтверждает лишь, что `/` отдаёт HTML. Случайная правка CSS или разметки может незаметно сломать внешний вид. Скриншотные тесты фиксируют эталонный вид ключевых состояний страницы. Они падают при любом непреднамеренном изменении — и при обычной сборке, и сразу после правок Claude в файлах интерфейса.

## What Changes

- Скриншотные тесты на Playwright Test (Node) в отдельной директории `ui-tests/`. Каждое ключевое состояние страницы сравнивается с эталонным скриншотом, эталоны хранятся в git.
- Тесты запускают собранное приложение на свободном порту с фиксированным набором тестовых данных во временном файле. Данные пользователя не затрагиваются.
- Интеграция в Gradle:
  - `./gradlew screenshotTest` — проверка, входит в `./gradlew check` и `./gradlew build`;
  - `./gradlew screenshotUpdate` — обновление эталонов при намеренном изменении внешнего вида.
- Node и браузер скачиваются сборкой, заранее устанавливать Node не нужно.
- Хук Claude Code (`PostToolUse`): после правок Claude в `src/main/resources/static/` запускается `screenshotTest`, и при расхождении Claude получает отчёт.
- Правила в `CLAUDE.md`: когда и как обновлять эталоны, как смотреть diff.

Вне рамок этого изменения:
- поведенческие e2e-тесты сценариев `cards-web-ui`, то есть замена ручной проверки — их можно добавить отдельным изменением на той же инфраструктуре;
- браузеры, кроме Chromium;
- настройка CI.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Изменение касается только инструментов тестирования, поведение системы не меняется, поэтому для изменения установлен `skip_specs: true`.

## Impact

- `ui-tests/`: `package.json`, `package-lock.json`, `playwright.config.ts`, тесты, эталонные скриншоты, тестовые данные.
- `build.gradle.kts`: плагин `com.github.node-gradle.node`, задачи `screenshotTest` и `screenshotUpdate`, зависимость `check` → `screenshotTest`.
- `.claude/settings.json` и `.claude/hooks/`: хук `PostToolUse`.
- `.gitignore`: `ui-tests/node_modules/`, отчёты и результаты Playwright, `.gradle/nodejs`.
- `CLAUDE.md`: раздел о скриншотных тестах.
- Время `./gradlew build` вырастет: запуск приложения и браузера займёт примерно 15–30 с. Первый запуск дольше из-за скачивания Node и Chromium.
