# Spec Delta

## ADDED Requirements

### Requirement: Удаление карточки в списке
На странице всех карточек каждая карточка SHALL иметь кнопку «Удалить». Нажатие MUST показать на этой карточке вопрос «Удалить карточку?» с кнопками «Да» и «Отмена», не удаляя карточку. «Да» MUST удалить карточку на сервере и убрать её из списка без перезагрузки страницы; «Отмена» MUST вернуть кнопку «Удалить» без изменений. Кнопки удаления MUST NOT раскрывать ответ карточки.

#### Scenario: Подтверждение удаления
- **WHEN** пользователь нажимает «Удалить» на карточке
- **THEN** на карточке появляется «Удалить карточку?» с кнопками «Да» и «Отмена», а карточка остаётся в списке и в хранилище

#### Scenario: Удаление после подтверждения
- **WHEN** пользователь нажимает «Удалить», затем «Да»
- **THEN** карточка исчезает из списка, остальные карточки остаются в прежнем порядке, а после перезагрузки страницы удалённой карточки нет

#### Scenario: Отмена удаления
- **WHEN** пользователь нажимает «Удалить», затем «Отмена»
- **THEN** вопрос подтверждения исчезает, на карточке снова кнопка «Удалить», и карточка остаётся в хранилище

#### Scenario: Удалена последняя карточка
- **WHEN** в списке одна карточка, и пользователь удаляет её
- **THEN** страница показывает сообщение о том, что карточек пока нет, и ссылку на страницу добавления

#### Scenario: Кнопка удаления не раскрывает ответ
- **WHEN** пользователь нажимает «Удалить» на карточке со скрытым ответом
- **THEN** ответ остаётся скрытым

### Requirement: Ошибка удаления карточки
Если сервер недоступен или ответил ошибкой при удалении, страница MUST оставить карточку в списке и MUST показать на ней сообщение об ошибке. Кнопка «Удалить» MUST снова стать доступной для повторной попытки.

#### Scenario: Сервер недоступен при удалении
- **WHEN** пользователь подтверждает удаление, а сервер не отвечает
- **THEN** карточка остаётся в списке, на ней показано сообщение об ошибке, и кнопка «Удалить» доступна
