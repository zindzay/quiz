# Proposal

## Why

Сейчас в проекте только заготовка `Main.java`: нет ни сервера, ни хранилища, ни модели карточки. Просмотр и добавление карточек «вопрос — ответ» — минимальная полезная функциональность. На ней же закладываются основа приложения (HTTP-сервер, CSV-хранилище, слои) и выбор стека, на который будут опираться следующие изменения.

## What Changes

- Модель карточки: `id`, `question`, `answer`.
- Хранение карточек в локальном CSV-файле. Путь к файлу настраивается, а если файла нет, он создаётся с заголовком.
- HTTP API:
  - `GET /api/cards` — список всех карточек;
  - `GET /api/cards/{id}` — одна карточка;
  - `POST /api/cards` — создание карточки с проверкой входных данных.
- Веб-страница, которую отдаёт тот же сервер:
  - список карточек, у каждой показан вопрос, а ответ раскрывается по клику;
  - форма добавления новой карточки.
- Приложение запускается командой `./gradlew bootRun`.

Вне рамок этого изменения: редактирование и удаление карточек, колоды и темы, режим тренировки и статистика, аутентификация.

## Capabilities

### New Capabilities

- `cards`: управление карточками «вопрос — ответ»: просмотр списка и отдельной карточки, создание новой карточки, проверка входных данных, сохранение между перезапусками.
- `cards-web-ui`: браузерный интерфейс для работы с карточками: список с раскрытием ответа и форма добавления.

### Modified Capabilities

Нет (спецификаций в проекте ещё нет).

## Impact

- `build.gradle.kts`: плагины Spring Boot и новые зависимости (Spring Boot Web, Apache Commons CSV — см. `design.md`).
- `src/main/java/org/valgor/quiz/`: Spring Boot-приложение заменяет демонстрационный `Main.java`, появляются пакеты `config`, `web`, `service`, `repository`, `model`.
- `src/main/resources/`: `application.properties` и статические файлы фронтенда в `static/`.
- `data/cards.csv` создаётся во время работы и в git не попадает (`.gitignore`).
