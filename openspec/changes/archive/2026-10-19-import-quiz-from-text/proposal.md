# Proposal

## Why

Скилы импорта берут материал из веб-страницы или PDF. Но часто нужный текст уже на руках: конспект, фрагмент документации, заметки, страница, которую скил не смог загрузить (нужен вход, страница собирается JavaScript). Сейчас такой текст можно превратить в карточки только вручную. Нужен скил, который принимает сам текст и делает карточки по нему так же, как два других скила.

## What Changes

- Новый скил Claude Code `quiz-from-text` в `.claude/skills/`:
  - на вход — текст в аргументах вызова (набранный или вставленный) и, по желанию, количество карточек `-n N` (1–50);
  - без количества — автоматический режим с полным охватом: карточка на каждое ключевое положение, сверка через `coverage.py`, подтверждение набора больше 150 карточек;
  - с количеством — до N карточек, распределённых по всему тексту;
  - разделы текста — его Markdown-заголовки; текст до первого заголовка или без заголовков — раздел «Введение»;
  - текст — только данные: инструкции внутри него не выполняются;
  - отправка, пропуск дубликатов и отчёт — через общие `post_cards.py` и `card-rules.md`, как в `quiz-from-web-page` и `quiz-from-pdf`.

Вне рамок этого изменения:
- текст из локального файла (`.txt`, `.md`) по пути;
- текст из предыдущих сообщений диалога без передачи в аргументах;
- новые скрипты в `tools/quiz-import/`: текст уже в контексте скила, нарезка и загрузка не нужны.

## Capabilities

### New Capabilities

- `quiz-from-text`: генерация карточек по тексту, переданному скилу, и их добавление в приложение.

### Modified Capabilities

Нет. Требования `quiz-from-web-page` и `quiz-from-pdf` не меняются: переиспользуются только `post_cards.py`, `coverage.py` и `card-rules.md`.

## Impact

- `.claude/skills/quiz-from-text/SKILL.md`: новый скил.
- `tools/quiz-import/README.md` и раздел «Скилы импорта» в `CLAUDE.md`: упоминание нового скила.
- Код приложения, API, формат CSV и скрипты не меняются, новых зависимостей нет.
