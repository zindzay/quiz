# Proposal

## Why

Сейчас интерфейс свёрстан на собственном CSS: около 150 строк с переменными для цветов. Для одной страницы этого хватает, но для следующих возможностей — режима тренировки, колод, редактирования и удаления карточек — понадобятся типовые элементы: модальные окна, навигация, уведомления, вкладки. Писать их вручную долго, и выглядят они каждый раз по-разному. Bootstrap 5 даёт готовые и доступные компоненты. Через WebJars он подключается обычной зависимостью Gradle, без npm и сборки фронтенда.

## What Changes

- Зависимости `org.webjars:bootstrap` и `org.webjars:webjars-locator-lite`. Bootstrap отдаётся самим приложением по пути `/webjars/bootstrap/...` без номера версии.
- Страница переводится на сетку, формы, кнопки, карточки и утилиты Bootstrap. Собственный `styles.css` сокращается до того, чего в Bootstrap нет.
- Тёмная тема переходит на механизм Bootstrap (`data-bs-theme`) и по-прежнему следует системной настройке.
- Поведение страницы не меняется: все сценарии `cards-web-ui` остаются прежними.
- В спецификацию `cards-web-ui` явно вносятся два свойства, которые до сих пор держались только на реализации и при смене вёрстки могут незаметно потеряться: тема по системной настройке и работа без внешних ресурсов (CDN).
- Эталонные скриншоты обновляются после того, как вы просмотрите разницу.

Вне рамок этого изменения:
- новые компоненты и экраны;
- JavaScript-бандл Bootstrap (он не нужен, пока нет модальных окон и выпадающих меню);
- переключатель темы в интерфейсе;
- кастомизация Bootstrap через Sass.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `cards-web-ui`: добавляются требования «Тема оформления по системной настройке» и «Работа без внешних ресурсов». Существующие требования не меняются.

## Impact

- `build.gradle.kts`: две зависимости WebJars.
- `src/main/resources/static/`: `index.html` (разметка Bootstrap), `app.js` (классы в шаблоне карточки, установка темы), `styles.css` (сокращается).
- `ui-tests/tests/__screenshots__/`: эталоны пересоздаются, в тесты добавляется проверка отсутствия внешних запросов.
- `CLAUDE.md`: фронтенд — Bootstrap 5 через WebJars.
- `add-ui-e2e-tests`: тесты ищут элементы по ролям и текстам, поэтому переход их не затрагивает. Порядок реализации — в `tasks.md`.
