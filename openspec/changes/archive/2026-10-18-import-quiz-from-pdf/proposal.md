# Proposal

## Why

Учебный материал часто лежит в PDF: конспекты, учебники, документация. Скил импорта с веб-страницы такие файлы не обрабатывает, и карточки по ним приходится составлять вручную. Нужен такой же скил, только с локальным PDF на входе: он составляет карточки по содержимому файла и добавляет их в приложение.

## What Changes

- Новый скил Claude Code `quiz-from-pdf` в `.claude/skills/`:
  - на вход — путь к локальному PDF, по желанию диапазон страниц и количество карточек;
  - скил читает документ, включая отсканированные страницы, частями и генерирует карточки по содержимому, распределяя их по документу;
  - для больших документов без указанного диапазона скил просит уточнить диапазон, а не обрабатывает всё подряд;
  - отправка, пропуск дубликатов и отчёт работают так же, как в `quiz-from-web-page`, через общий скрипт и общие правила генерации.

Вне рамок этого изменения:
- PDF по URL (файл нужно сначала скачать);
- защищённые паролем PDF;
- извлечение данных из таблиц и диаграмм в отдельные карточки;
- поле «источник» у карточки.

## Capabilities

### New Capabilities

- `quiz-from-pdf`: генерация карточек по содержимому локального PDF-документа и их добавление в приложение.

### Modified Capabilities

Нет. Требования `quiz-from-web-page` не меняются: переиспользуется только реализация (скрипт и файл правил).

## Impact

- `.claude/skills/quiz-from-pdf/SKILL.md`: новый скил.
- `tools/quiz-import/`: используется без изменений, а в `README.md` добавляется упоминание PDF-скила.
- `CLAUDE.md`: раздел «Скилы импорта» дополняется PDF-скилом.
- Зависит от изменений `add-card-view-and-create` (API) и `import-quiz-from-web-page` (`post_cards.py`, `card-rules.md`).
