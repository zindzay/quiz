Протокол HTTP

Найти ПОИСК-ТЕКСТ

HTTP — протокол прикладного уровня для передачи гипертекста. Он работает по схеме «запрос — ответ»: клиент отправляет запрос, сервер возвращает ответ с кодом состояния. Протокол создан для обмена документами между браузером и веб-сервером.[1]

Протокол не хранит состояние между запросами, поэтому для сессий используются cookie и другие механизмы.

История[ПРАВИТЬ-ССЫЛКА]

Первую версию протокола, HTTP/0.9, разработал Тим Бернерс-Ли в 1991 году в ЦЕРН. Она поддерживала только метод GET и возвращала документ без заголовков. В 1996 году вышла версия HTTP/1.0 с заголовками и кодами состояния, а в 1997 году — HTTP/1.1 с постоянными соединениями.

ВРЕЗКА-ASIDE: интересный факт не по теме

Версия HTTP/2 опубликована в 2015 году и использует двоичный формат кадров. HTTP/3 работает поверх протокола QUIC и стандартизирован в 2022 году.

Методы

Метод запроса указывает действие над ресурсом. Основные методы перечислены ниже.

  • GET — получение ресурса.
  • POST — передача данных на сервер.
    • Форма отправляется методом POST.
  • DELETE — удаление ресурса.
  1. Клиент открывает соединение.
  2. Клиент отправляет запрос.
  3. Сервер отвечает.

Пример запроса:

GET /index.html HTTP/1.1
Host: example.com
    Accept: text/html

Заголовок Host обязателен в HTTP/1.1.

Коды состояния

Код состояния — трёхзначное число в первой строке ответа. Первая цифра задаёт класс ответа: 1xx — информационные, 2xx — успешные, 3xx — перенаправления, 4xx — ошибки клиента, 5xx — ошибки сервера.
